# Sistema de Gestión de Tareas – Home Solution

## 📌 Descripción general
Este proyecto final de la materia Programación II implementa un sistema de gestión de tareas y empleados utilizando **Programación Orientada a Objetos en Java**. El objetivo principal es modelar correctamente el dominio del problema, priorizando un diseño claro, extensible y mantenible.

El sistema permite:
- Gestionar empleados permanentes y contratados
- Asignar tareas a empleados
- Calcular costos de tareas según el tipo de empleado
- Administrar estados, retrasos y finalización de tareas
- Mantener información de clientes

---

## 🧱 Diseño y arquitectura

El diseño se basa en una correcta separación de responsabilidades, apoyándose en:
- **Interfaces** para definir contratos de comportamiento
- **Herencia** para reutilizar lógica común
- **Polimorfismo** para resolver comportamientos en tiempo de ejecución
- **Abstracción** para ocultar detalles de implementación
